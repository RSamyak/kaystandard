# Apps

Applies to local applications.  `repos.md` and `code.md` also apply.

## Stack

HTML interface in a local server or desktop shell.

## Principles

- Every supported desktop platform has a double-clickable launcher.
- The launcher checks prerequisites, prepares or reuses the build, starts the app, and opens its interface.
- An HTTP interface binds `127.0.0.1` by default.
